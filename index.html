Empezar es simple

Tres pasos para tener todo funcionando

Descargá el archivo comprimido

Hacé clic en Descargar para Windows. Se baja Devxis-Setup.zip con la última versión publicada.

Extraelo e instalá

Extraí el archivo .zip (clic derecho → Extraer todo) y ejecutá Devxis-Setup.exe. Seguí el asistente: no requiere configurar servidores ni bases de datos.

Activá tu licencia

Ingresá el email y el código de licencia que te entregamos. Después la app queda lista para usar.

Compatibilidad

Requisitos del sistema

Antes de instalar

  • Windows 10 u 11, 64 bits
  • 300 MB de espacio libre en disco
  • Conexión a internet solo para activar o verificar la licencia
  • Los datos se guardan en %APPDATA%\devxis-desktop
Preguntas frecuentes

Lo que suelen preguntarnos

¿Dónde se guardan mis datos?

En una base de datos local dentro de tu usuario de Windows. No se suben a ningún servidor: la información comercial queda en tu computadora.

¿Necesito internet para usarla?

No para trabajar. Solo se usa la conexión al activar la licencia y en las verificaciones periódicas. Si no hay internet, la app sigue funcionando dentro del período de gracia.

¿Cómo actualizo a una versión nueva?

Descargá el archivo .zip desde esta página, extraílo y ejecutá el instalador sobre la versión anterior. Tus datos y tu licencia se conservan.

¿Cómo obtengo una licencia?

Escribinos a alexis.r4995@gmail.com y te enviamos el email y el código de activación.
